# Contributing to Privacycoin AI

Bedankt voor je interesse in Privacycoin AI!

## Huidige status

Dit is een **concept-stadium** project. De focus ligt op:
1. Whitepaper en documentatie
2. Technische due diligence van PRCY + PIVX
3. Tokenomics en agent-protocol specificaties
4. Eerste zkML experimenten

## Hoe bij te dragen

1. Open of kies een bestaande [Issue](https://github.com/corblanksma-gif/Privacycoin-AI/issues)
2. Fork de repository
3. Maak een branch (`git checkout -b feature/jouw-feature`)
4. Commit je wijzigingen
5. Open een Pull Request

## Prioriteiten (zie ook Issues)

- Tokenomics paper (#2)
- Due diligence PRCY + PIVX (#3)
- Agent Protocol specificatie (#4)
- zkML research (#5)

## Code of Conduct

Wees respectvol, constructief en gericht op het bouwen van een open, privacy-first AI-ecosysteem.
